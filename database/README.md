# Base de datos

En esta carpeta se colocara el script:

```text
bd_toolbox_gestor_web.sql
```

El script incluira:

- Creacion de la base de datos `bd_toolbox_gestor_web`.
- Tablas `categoria`, `proveedor`, `cliente`, `producto`, `venta` y `detalle_venta`.
- Claves primarias y foraneas.
- Restricciones basicas.
- Datos de prueba para una ferreteria peruana.

Antes de ejecutar el script, iniciar MySQL desde XAMPP y confirmar que el puerto `3306` este activo.
